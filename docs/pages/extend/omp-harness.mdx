# Using the OMP Harness

Centaur can run [oh-my-pi](https://github.com/can1357/oh-my-pi) (OMP) as a
session harness alongside Codex, Claude Code, Amp, Nanocodex, Hermes, and Pi.
Start a Slack thread with `--omp`, or set `omp` as a Slack channel default. OMP
is available from Slack only for now.

The sandbox keeps one `omp --mode rpc --no-ui` process per thread. Assistant
text renders when complete, with commentary distinguished from the final
answer and thinking shown as it happens. A turn ends on `prompt_result`; if
background work is still pending, it stays open through that work's follow-up,
until `session_settled`. Each tool call shows up as its own tool item.

OMP saves the session on disk in a directory derived from the thread key, so
an interrupt (which stops the OMP process, as with Claude Code), a model switch,
or a sandbox restart with persistent state resumes the same conversation.
JSON-RPC `turn/steer` sends an update to the running turn; blocks input received
during a turn queues as the next turn, as with Pi.

## Credentials

OMP reads `ANTHROPIC_API_KEY` and `OPENAI_API_KEY` from the sandbox
environment, where api-rs sets iron-proxy placeholders that the proxy replaces
with the real keys. The sandbox has the Anthropic placeholder only when
`CLAUDE_CODE_AUTH_MODE` is `api_key`, and the OpenAI one only when
`CODEX_AUTH_MODE` is `api_key`. api-rs refuses to start with `omp` as the default
harness when `CLAUDE_CODE_AUTH_MODE` is `access_token`.

OMP also has a native auth broker. Set `OMP_AUTH_BROKER_URL` and
`OMP_AUTH_BROKER_TOKEN` in the sandbox environment to fetch credentials from
`omp auth-broker serve` instead of the local credential store. When a broker is
configured, an unreachable broker fails the session; OMP does not fall back to
local credentials. Environment values take precedence over
`auth.broker.url`/`auth.broker.token` in `~/.omp/agent/config.yml` and the
`~/.omp/auth-broker.token` file. OMP resolves the broker connection only from
those environment variables and the global config file; project settings and
`PI_CONFIG_FILES` overlays never redirect credentials.

Treat that bearer as a high-value shared credential: it can read any credential
the broker serves. Scope a deployment to one trusted owner or tenant and keep
each tenant's secrets separate; do not share one subscription across users. Put
`OMP_AUTH_BROKER_URL` in `sandbox.extraEnv`, but deliver the token from a
Kubernetes Secret rather than values or inline config: expose
`OMP_AUTH_BROKER_TOKEN` to the api-rs process under exactly that name (for
example as an unprefixed key in `secretManager.existingSecretName`) and add it
to `apiRs.extraEnv.SESSION_SANDBOX_PASSTHROUGH_ENV` so api-rs forwards it into
each sandbox. This passthrough is not an iron-proxy placeholder: the real bearer
appears as a plain environment value in the sandbox PodSpec (including
workflow-host sandboxes), where any agent command can read it. Treat the sandbox
and its logs as trusted for that token, and scope or rotate it accordingly.
Keep secrets out of `OMP_CONFIG_OVERLAY`.

## Configuration

| Variable | Purpose |
|---|---|
| `CENTAUR_OMP_MODEL` | Default model as `provider/modelId`, for example `anthropic/claude-opus-4-8` or `openai/gpt-5.5`. When unset, OMP chooses the model for a new thread and a resumed thread keeps its saved model. |
| `CENTAUR_OMP_BIN` | OMP executable (default: `omp` on `PATH`). |
| `CENTAUR_OMP_SESSION_ROOT` | Session root (default: `~/.omp/centaur-sessions`). |
| `OMP_CONFIG_OVERLAY` | YAML text (not a path) that OMP applies as its last `PI_CONFIG_FILES` overlay. Use it for settings with no environment binding, such as `modelRoles` and `retry.fallbackChains`. Unset writes no file. |

Set these through `sandbox.extraEnv`; no chart template change is required.
Slack mirrors `CENTAUR_OMP_MODEL` for its model display. A per-thread
`--model provider/modelId` overrides the default.
OMP resolves the provider/model pair; there is no static model allowlist. A
rejected model fails that turn, and later turns use the last working model. With
no model set, OMP will not resume a thread on another model when its saved model
is no longer available, so the thread's turns fail until it names one.

Turns run at the `high` thinking level unless `-rsn <level>` sets one for that
turn (`none` turns thinking off). OMP clamps the level to the model's capabilities.
A turn without an override restores `high`, including after a session resumes.

### Settings overlay

For OMP settings without an environment binding, set `OMP_CONFIG_OVERLAY` to
YAML text (not a path) through `sandbox.extraEnv`:

```yaml
sandbox:
  extraEnv:
    OMP_CONFIG_OVERLAY: |
      modelRoles:
        default: anthropic/claude-opus-4-8
        smol: openai/gpt-5.5
      retry:
        fallbackChains:
          default:
            - openai/gpt-5.5
```

At startup the sandbox entrypoint writes the text to
`~/.config/centaur/omp-config-overlay.yml` with mode `0600` and appends it to
OMP's native `PI_CONFIG_FILES` list. It never rewrites the persistent
`~/.omp/agent/config.yml`. When `OMP_CONFIG_OVERLAY` is unset (or empty), it
writes no file and leaves `PI_CONFIG_FILES` alone.

`PI_CONFIG_FILES` is colon-separated. OMP merges the persistent config, project
settings, then each listed file in order, so later files win for keys they
define. Centaur appends this overlay last: it overrides keys from existing
overlays, and keys it omits still fall through to them. OMP treats explicit
overlays as strict, so invalid YAML or a missing overlay file fails startup
rather than being ignored. `OMP_AUTH_BROKER_URL` and `OMP_AUTH_BROKER_TOKEN`
take precedence over the corresponding `auth.broker.*` config values.

Do not put credentials in `OMP_CONFIG_OVERLAY`; deliver
`OMP_AUTH_BROKER_TOKEN` from a Secret as described above. Check effective values
from an agent turn, or from any process that inherited the entrypoint
environment:

```bash
omp config get modelRoles
omp config get retry.fallbackChains
```

A `kubectl exec` shell does not inherit `PI_CONFIG_FILES` from the entrypoint,
so it reports only the persistent and project config. Pass the runtime overlay
explicitly, and prepend any other configured overlays to match the live merge
order:

```bash
kubectl exec <sandbox-pod> -- env \
  PI_CONFIG_FILES=/home/agent/.config/centaur/omp-config-overlay.yml \
  omp config get modelRoles
```
